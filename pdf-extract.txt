导航网站 开发文档
技术栈·结构·功能·数据库·接口·部署·中转·性能安全
一、项目概述
一个可后台管理的中文导航网站。前台展示分类卡片、广告、横幅、跑马灯、卡片详情页与评论;后台提供
链接/分类/广告/页面/颜色/渐变/弹窗公告/访客统计/用户与评论/投稿审核等管理。支持用户注册登录、图
形验证码、卡片详情评论(图片+验证码)、自动生成卡通头像、移动端底部导航、防失联中转等。
• 代码仓库:github.com/sym155255-eng/mm(dist 已纳入版本库,服务器免构建)
• 部署目录:~/ddd 后端端口:3001 线上主域名:1558686.xyz 备用:1558686.bond
二、技术栈
• 前端:React 18 + Vite 5 + react-router-dom 6,内联样式对象 + index.css/App.css 响应式,@vitejs/plugin-
legacy 兼容老旧浏览器
• 后端:Node.js 20 + Express 4
• 数据库:sql.js(纯 JS 的 SQLite,单文件 data/nav.db),写盘防抖批量保存(最多每 0.8 秒一次)
• 鉴权:JWT(7 天)+ bcryptjs;后台接口 requireAdmin 校验管理员
• 实时:SSE(/api/events)+ 前端 20 秒轮询兜底
• 部署:PM2 守护 + 1Panel/OpenResty 反代 → 127.0.0.1:3001,Let's Encrypt HTTPS

四、核心功能
1. 前台
• 首页:分类侧栏、卡片网格(电脑5/平板4/手机2列)、子分类标签、广告区(卡片/圆形两样式)、横幅、霓虹
跑马灯、横向导航;弹窗公告;移动端底部导航(首页/投稿/我的,滚动自动隐藏)
• 卡片点击弹窗(主链接+子链接+详情);详情页 /sites/:id:头部含横幅/跑马灯/广告,标题行(标题·分类·打开网
站·子链接同行),评论区
• 描述渐变文字:卡片/广告描述可设三色渐变 + 来回扫动动画
2. 用户与评论
• 注册/登录:用户名+密码(+可选昵称),均需图形验证码;20 分钟无操作自动退出
• 评论:需登录+图形验证码,可传图片(限本站 /uploads,≤5MB),自动卡通头像,分页加载;管理员显示「管理
员」

--- page 2 ---
• 投稿:登录用户提交卡片链接(不含子链接)→ 后台审核通过后写入 links 发布
3. 后台管理
• 链接/分类/子分类/导航/页面/广告/跑马灯/图片管理;颜色管理(全局+单条)、颜色渐变(卡片/广告描述,分
类筛选)
• 弹窗公告、访客统计(真实 PV/UV)、用户管理(自定义昵称/角色色)、评论审核、投稿审核、网站设置
• 图标:可手动上传(文件名 up_),批量「重抓图标」会跳过手动上传的,不覆盖
五、数据库主要表
• users(id,username,password,role,nickname,nickname_color,role_color)
• categories(page_group)/sub_categories/links(views,badge,desc_color,desc_gradient...)/sub_links
• ads(position,desc_gradient...)/ad_sub_links/banners/notices/navs/pages/settings(键值)
• comments(link_id,user_id,nickname,image_url,visible)/submissions(投稿,status)
• stats_daily(date,pv,uv)/visit_ips(date,ip 去重 UV)
六、主要接口
• 公共 /api/public:GET /data?group= 首页数据;GET /link/:id 详情(浏览+1);GET /captcha;GET /
comments/:linkId?offset=&limit=;POST /comment(登录+验证码);POST /comment-image;POST /visit 埋
点;POST /submission
• 鉴权 /api/auth:POST /login、/register(均需验证码)、/change-password
• 后台 /api/admin(管理员):links/categories/ads/... CRUD;GET /stats;submissions 审核;users;settings;refetch-
icons
七、部署与更新
本地构建、服务器免构建(因服务器内存小)
• 流程:本地改代码 → npm --prefix client run build(生成 dist 并提交)→ git push
• 服务器:cd ~/ddd && bash update.sh(git pull + 装后端依赖 + pm2 重启,不再 build)
全新机器部署
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs git && npm i -g pm2
mkdir -p ~/ddd && cd ~/ddd
git clone https://github.com/sym155255-eng/mm.git . # 或上传 zip 解压
npm --prefix server install
pm2 start server/src/index.js --name nav-site
pm2 save && pm2 startup systemd -u root --hp /root
数据库自动备份(server/.env)
BACKUP_REPO=https://<token>@github.com/<用户名>/nav-db-backup.git
BACKUP_INTERVAL_MIN=60
换服务器从备份恢复(先停服务再覆盖 nav.db)
pm2 stop nav-site
git clone https://<token>@github.com/<用户名>/nav-db-backup.git /tmp/dbbak
cp /tmp/dbbak/nav.db ~/ddd/data/nav.db && rm -rf /tmp/dbbak
pm2 start nav-site
八、防封 / 中转架构
• 多备域名,全部解析到服务器;一个被墙换下一个
• 中转服务器:1Panel 反向代理 → http://主服务器IP:3001;中转域名 + HTTPS。主域名被墙时用中转域名
• 隐藏源站:所有域名指向中转、主服务器 3001 只放行中转 IP(iptables),公网查不到主 IP
• 前台无需改代码:相对路径 + CORS:* + JWT 存 localStorage,换域名/经中转都正常

九、性能与安全
• 写盘防抖:内存即时更新、磁盘最多每 0.8 秒合并写一次;进程退出前刷盘
• 评论图片仅接受本站 /uploads 路径(防盗链/XSS);删除卡片级联删除其评论与图片文件
• 验证码 5 分钟过期、一次性;登录失败按 IP 锁定;JWT 密钥存 data/.jwt_secret
• 评论分页(每页 20);移动端禁缩放(viewport + 手势拦截 + touch-action)

导航网站 CSS 样式布局
断点·电脑端布局·移动端适配·动画 + index.css/App.css/内联样式全文
本项目电脑端样式由两部分组成:(1) index.css 全局 CSS 变量(:root)+ 基础样式 + 动画;(2) 各页面组件内的内联
样式对象(Home.jsx 的 styles、SiteDetail.jsx 的 s 等)。移动端适配集中在 App.css 的 @media 媒体查询,用类名
钩子 + !important 覆盖电脑端默认值。
一、断点与列数
• 电脑(桌面):> 1024px — 卡片/广告 5 列(App.css),侧栏 + 主区横向布局
• 平板:769–1024px — 4 列
• 手机:≤ 768px — 2 列,侧栏变左侧滑出抽屉,顶栏固定,底部导航,间距全面收紧
• 窄屏弹窗:≤ 680px — 编辑弹窗收紧
二、电脑端布局结构
首页
• 顶部 .site-header(sticky)— logo + 搜索框 + 管理后台入口
• 主体 .home-body — 左 .home-sidebar(分类,width 140,sticky)+ 右 main(横幅/跑马灯/广告/分类区块);电
脑端左对齐紧贴边缘
• 卡片网格 .link-grid — grid 5 列;卡片 = 图标(32) + 标题/描述
• 广告 .ads-row — grid;两种样式(卡片 / 圆形 .ad-circle)
详情页 /sites/:id
• 容器 maxWidth 1100 居中;头部复用横幅/跑马灯/广告;正文卡片标题行(标题·分类·打开网站·子链接同
行)+ 评论区(列表分页 + 表单)
三、移动端适配要点(App.css @media ≤768px)
• 底部导航 .bottom-nav:fixed 底部,滚动时加 .hidden 平移隐藏
• 顶部搜索栏 fixed 固定、调矮;内容 padding-top 避让;三条杠 32px
• 侧边栏 fixed 抽屉,translateX(-100%) 隐藏,.open 滑入 + 遮罩
• 卡片图标放大(.card-ico 42px / img 30px),图标与文字 gap 4
• 广告圆形 .ad-circle:≥10 个一行 5、<10 个一行 4,图标 50px 圆形,隐藏描述
• 详情页:顶栏隐藏;标题行收紧一行;子链接独立一行可横滑;评论表单 图片/验证码/发表 同一行
• 后台:侧栏抽屉、顶栏固定、宽表格横向滚动、颜色渐变筛选同行
• 禁缩放:viewport user-scalable=no + html touch-action:manipulation + JS 拦 iOS 手势/双击
四、动画(index.css)
• marquee 跑马灯横向滚动;neonGlow 霓虹边框呼吸;flowText/gradFlow 渐变流光(描述渐变来回扫
